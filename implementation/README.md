# Исполняемый фрагмент Ритмо

Доменный прототип Java 21: создание, переименование и удаление привычки,
идемпотентная отметка и отмена сегодня, контроль владельца и expectedDate,
текущая серия и очки. Это начало реализации T03…T07 итераций I1/I2,
а не готовый продукт и не подтверждение соблюдения календаря ЛР4.

Проверка без внешних зависимостей (из корня репозитория):

```sh
build_dir=$(mktemp -d)
javac --release 21 -encoding UTF-8 -d "$build_dir" lab5/implementation/src/by/bsuir/ritmo/HabitService.java lab5/implementation/test/by/bsuir/ritmo/DomainChecks.java
java -cp "$build_dir" by.bsuir.ritmo.DomainChecks
```

Данные живут только в памяти; `synchronized` сериализует операции одного процесса.
В рабочей реализации ему соответствуют транзакции PostgreSQL и блокировка Habit.
Метод принимает доверенный owner UUID: его должен извлекать из сессии серверный слой.
HTTP, CSRF, регистрация, адаптивный хеш пароля, PostgreSQL, React и CSV ещё не реализованы.
Проверки доменного прототипа не заменяют AT-01…13 и не доказывают свойства БД.
