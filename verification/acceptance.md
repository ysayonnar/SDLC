# План проверки и приёмки Ритмо

Версия 1.1, 28.10.2026. Эти сценарии предназначены для будущей реализации. Статус всех AT — «не выполнена»: ЛР4 выпускает документацию, а не готовое приложение. AT-07 отложена вместе со значком CR-01. Источник — [реестр требований](../requirements/system-requirements.md).

## Среда и данные

Локальные Java, React, PostgreSQL и Chrome по VIEW-05. Две учётные записи A/B, несколько привычек, управляемый тестовый Clock Europe/Minsk. История дат для серий создаётся только тестовой фикстурой в изолированной БД; публичного API для изменения прошлых дат нет. Перед тестами БД очищается. Для отказов используются тестовые транзакции, рабочая БД пользователя не повреждается.

## Приёмка итераций

I1: AT-01/02 и часть AT-08 по входу/владельцу. I2: AT-03…06 и повторы/конкуренция из AT-12. I3: полный повтор всех обязательных AT, включая AT-08…13. Для каждого выполнения сохраняются версия сборки, дата, входные данные, фактический результат и дефект при несовпадении. Наличие тест-кейса не означает успешное прохождение.

## Проверка документов ЛР4

Автоматизированная проверка `tools/check_lab4.py` контролирует арифметику четырёх планов, допустимость приоритетов, зависимости, покрытие исходных ID, локальные ссылки и отсутствие старых файлов `main`/`lab3`. Отчёт DOCX отдельно проверяется по структуре OOXML и рендеру каждой страницы. Подтверждение этих проверок относится только к документации.
