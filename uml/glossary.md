# Глоссарий проекта Ритмо

Версия 1.0, 16.11.2026. Источник: SRS 0.2 и SDD 1.1 ЛР4.

| Термин | Определение | Элемент модели |
|---|---|---|
| Ритмо | Веб-приложение для учёта ежедневных привычек и просмотра личного прогресса | Система |
| Гость | Посетитель без действующей сессии; регистрируется и входит | Actor Guest |
| Пользователь | Владелец сессии, работающий только со своими привычками | Actor User; app_user |
| Привычка | Ежедневное действие с названием, владельцем и уникальным ID | habit |
| Отметка | Факт выполнения одной привычки за одну календарную дату | completion |
| Серверная дата | Текущая дата из Clock в часовом поясе Europe/Minsk | serverDate |
| Ожидаемая дата | Дата, отображённая клиенту и отправленная при изменении отметки | expectedDate |
| Серия | Количество последовательных дней с отметками, считая от сегодня или вчера | streak |
| Очки | Десять очков за каждую сохранённую отметку существующей привычки владельца | totalPoints |
| История | Множество сохранённых дат выполнения привычки; прошлые даты через API не меняются | D; completion_date |
| Сессия | Серверная связь cookie с вошедшей учётной записью | session.userId |
| Владелец | Пользователь, чей ID записан в привычке; берётся из сессии | owner_id |
| CSV | Выгрузка date;habit;points в UTF-8 с BOM и разделителем «;» | ExportService |
| Идемпотентность | Повтор одного PUT или DELETE сохраняет тот же эффект для состояния | UC-06, UC-07 |
| Транзакция | Группа операций, фиксируемая целиком или целиком отменяемая | commit / rollback |
| Снимок прогресса | Согласованные дата, список привычек, серии и сумма очков одного чтения | ProgressSnapshot |
| Прецедент | Взаимодействие с системой ради результата актёра либо включаемый фрагмент | UC-01…11 |
| Сторожевое условие | Логическое условие, разрешающее переход или ветвь | [expectedDate = today] |
| Линия жизни | Участник взаимодействия и его существование во времени | VIEW-09 |
| Включение | Обязательное выполнение общего поведения прецедента | «include» UC-11 |
| DAY_CHANGED | Конфликт даты; данные перечитываются без автоматического повтора действия | HTTP 409 |
| Значок | Награда за серию от семи дней; исключена из текущего выпуска CR-01 | REQ-FUNC-008, отложено |
