# Динамические модели Ритмо

Редакция графики: 25.11.2026.

- `images/*.png` — версии 300 dpi для отчёта;
- `images/*.svg` — векторные рисунки;
- `models/*.drawio` — редактируемая геометрия;
- `models/*.puml` — семантические модели UML;
- `images/sequence-complete-today-a3.pdf` — векторный лист А3 с внедрёнными шрифтами;
- `images/приложение-Б.pdf` — обновлённая копия прежнего файла PDF.

В текущем отчёте финальный лист имеет обозначение приложения В; старое имя второй копии PDF сохранено.

## Оформление

Рисунки 3.2 и 3.3: ГОСТ 19.701-90 по п. 3.12.2–3.12.4 СТП 01–2024.
Основное направление сверху вниз и слева направо без наконечника; обратное — открытая стрелка 60°.
Контуры и потоки толщиной 0,3 мм; одинаковые процессы одной схемы имеют одинаковые размеры.
Рисунки 3.1, 3.4 и последовательность сохраняют обозначения UML; оформление листов и надписей — по СТП.
Машина состояний относится к фиксированной дате d, не удаляет историю при смене дня.
Последовательность содержит основной успешный поток; исключения описаны в прецедентах.
А3: 420 × 297 мм, рамка 20 мм слева и 5 мм с остальных сторон, штамп 185 × 55 мм.

## Воспроизведение

`python uml/render_diagrams.py` создаёт SVG, draw.io, PNG и отдельный PDF по общей геометрии.
Требуются ReportLab, Poppler, Arial, Arial Bold, Arial Narrow Italic и Times New Roman.
Оформление внутри отчёта нужно обновлять отдельно; замена файлов изображений сама по себе не меняет DOCX.
